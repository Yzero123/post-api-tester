填目标地址、认证信息与 JSON 请求体，直接在浏览器里发 POST 请求，查看响应文本、图片视频、状态码、耗时、响应头与原始返回。无需安装任何东西。

自动轮询任务（异步接口查结果时用）

识别规则：读取响应里的 data[].status、tasks[].status 或顶层 status； 全部变成 succeeded / failed / canceled 这类终态就停止。 找不到状态字段、或返回 4xx/5xx 时会立刻停下并说明原因。

高级：跨域代理（接口不支持 CORS 时才需要）

绝大多数主流接口都允许浏览器跨域直连，这一项留空即可。
只有目标接口没返回 Access-Control-Allow-Origin 时才需要填。
填法：前缀里含 {url} 就替换成编码后的地址，否则直接把编码后的地址接在后面。
没有代理？用 Cloudflare Worker 免费搭一个，脚本见仓库 proxy/cloudflare-worker.js。
注意：走代理时你的 API Key 会经过那台代理服务器，请只填自己可控的代理。
